**MyProblems** — это персональная интерактивная среда для ведения базы задач по программированию и запуска кода прямо в браузере.

### Ключевые особенности

- **Автономное исполнение кода:** Запуск JavaScript реализован локально через Web Workers. Никаких внешних серверов — максимальная скорость и полная приватность.
- **Полноценная IDE в браузере:** Встроенный редактор на базе Monaco/Ace с подсветкой синтаксиса и автодополнением.
- **Продвинутая работа с данными:** Локальное хранение сессий плюс поддержка File System Access API для прямого сохранения файлов на вашем компьютере.
- **Кастомизация задач:** Гибкая разметка карточек с указанием сложности, категорий и развернутого описания.

###  Технологический стек

- **Frontend:** React 19, TypeScript, MobX, Tailwind CSS
- **Сборщик:** Vite
- **Среда выполнения:** Local JS Runtime (Web Workers)
- **Архитектура:** Модульная (на принципах Feature-Sliced Design)
